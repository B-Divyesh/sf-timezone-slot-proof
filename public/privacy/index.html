05 Privacy

Privacy without a calendar login.

Short version: booking hours and calendar files stay in your browser while you use this check.

Data the tool uses

The check uses the booking hours you enter and any calendar file you choose.

Storage in this browser

Weekly booking hours can be saved in this browser. Calendar-file contents stay only in the open page.

Review links and exports

Calendar-file contents are not added to review links. CSV exports download to your device.

Network and measurement

The sample check makes no third-party requests. The host receives standard web request data in infrastructure logs.
